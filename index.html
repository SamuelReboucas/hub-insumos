🔄 Automações n8n — Conciliação de Estoque e Notas Fiscais

Dois workflows de automação de operação de estoque para e-commerce/varejo multi-filial, eliminando conferência manual entre ERP, WMS e notas fiscais.

1. Estoque Unificado — ERP + WMS + Alertas Críticos

Consolida diariamente o saldo de estoque de duas fontes distintas e emite alerta automático quando a divergência ultrapassa o limiar de criticidade por curva ABC.

Fluxo

  1. 23h35 — extrai saldo ERP (Protheus) via Metabase, soma quantidade disponível + reservada + empenhada
  2. 09h00 (dia seguinte) — extrai saldo WMS via XLSX no Google Drive, cruza com o ERP da véspera
  3. Classifica cada SKU por curva ABC e calcula divergência absoluta
  4. Aciona alerta no Google Chat quando: AA/A < 1.000un · B < 300un · C < 200un
  5. Cruza SKUs críticos com notas pendentes via GTIN antes de notificar — evita falso-positivo por nota ainda não lançada

2. Não Classificadas — Zerando o backlog de notas fiscais

Zera o backlog de notas fiscais que ficam pendentes de classificação no ERP/WMS.

Fluxo

  1. Extrai notas não classificadas do Metabase (Protheus)
  2. Busca XLSXs de notas emitidas e recebidas no Google Drive
  3. Padroniza ambas as bases (nomenclatura de colunas divergente entre fontes)
  4. Executa Apps Script que cruza as bases e classifica automaticamente
  5. Grava resultado em abas estruturadas
  6. Envia resumo diário no Google Chat

Gatilho: 09:00 e 18:30 diariamente

Stack

n8n Google Apps Script Metabase API Google Sheets/Drive Google Chat Webhooks
